# Soft Copper

A separate Consilient Holdings website variation, hosted with GitHub Pages.

`index.html` is an unchanged copy of the supplied `Consilient Soft Copper.html`. Its images, vector wordmarks, fonts, CSS and JavaScript are embedded; no build step or external asset directory is required.

The original contact-form configuration is preserved. Verify its recipient-mailbox activation and message delivery before relying on enquiries.

Artwork, wordmark and other materials remain the property of their respective owners.
